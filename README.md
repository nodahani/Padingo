# پدینگو | Padingo

کارها و یادداشت‌هایت را ساده، سریع و کاملاً آفلاین مدیریت کن.
پدینگو نسخه‌ی فارسیِ [Pentastic](https://github.com/tanujnotes/Pentastic) است.

## درباره‌ی پدینگو

پدینگو فارسی‌سازی و توسعه‌ی اپ متن‌باز Pentastic است: رابط تمام‌فارسی و راست‌به‌چپ، تقویم جلالی، شروع هفته از شنبه، و هویت و آیکون جدید.
زیرِ همه‌ی این‌ها همان موتور ساده و بی‌دردسر Pentastic می‌تپد: صفحه‌ها، کارها، یادداشت‌ها و یادآورها — بدون حساب کاربری، بدون نیاز به اینترنت؛ داده‌هایت فقط روی دستگاه خودت می‌مانند.

## ویژگی‌ها

- 📋 صفحه‌ها و زیرصفحه‌ها برای مرتب‌کردن کارها و یادداشت‌ها
- ⏰ یادآور با اعلان — حتی بعد از ری‌استارت گوشی
- 🔁 کارهای تکرارشونده: روزانه، هفتگی، ماهانه و سالانه
- 📅 تقویم جلالی و میلادی، با انتخاب شروع هفته (شنبه، یکشنبه یا دوشنبه)
- 🌗 پوسته‌ی روشن و تیره
- 🇮🇷 رابط کاملاً فارسی و راست‌به‌چپ

## نصب

جدیدترین نسخه‌ی APK را از صفحه‌ی [Releases](https://github.com/nodahani/Padingo/releases) دانلود و نصب کن.
(اگر اندروید هشدار «منبع ناشناس» داد، فقط برای مرورگر یا فایل‌منیجری که با آن دانلود کرده‌ای اجازه‌ی نصب را فعال کن.)

## ساخت از سورس

پیش‌نیاز: JDK 17 و Android SDK (یا اندروید استودیو)

```bash
git clone https://github.com/nodahani/Padingo.git
cd Padingo
./gradlew :composeApp:assembleDebug
```

خروجی در `composeApp/build/outputs/apk/debug/` ساخته می‌شود.
