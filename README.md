## درباره‌ی پدینگو

پدینگو فارسی‌سازی و توسعه‌ی اپ متن‌باز Pentastic است: رابط تمام‌فارسی و راست‌به‌چپ، تقویم شمسی شروع هفته از شنبه، و هویت جدید.
زیرِ همه‌ی این‌ها همان موتور ساده و بی‌دردسر Pentastic می‌تپد: صفحه‌ها، کارها، یادداشت‌ها و یادآورها — بدون حساب کاربری و بدون نیاز به اینترنت؛ داده‌ها در فضای محلی برنامه نگه‌داری می‌شوند.

## ویژگی‌ها

- 📋 صفحه‌ها و زیرصفحه‌ها برای مرتب‌کردن کارها و یادداشت‌ها
- ⏰ یادآور با اعلان — حتی بعد از ری‌استارت گوشی
- 🔁 کارهای تکرارشونده: روزانه، هفتگی، ماهانه و سالانه
- 📅 تقویم شمسی و میلادی، با انتخاب شروع هفته (شنبه، یکشنبه یا دوشنبه)
- 🌗 پوسته‌ی روشن و تیره
- 🇮🇷 رابط کاملاً فارسی و راست‌به‌چپ

## حریم خصوصی و پشتیبان‌گیری

پدینگو داده‌ها را در فضای محلی برنامه نگه می‌دارد. در نسخه‌ی Android، پشتیبان‌گیری سیستم برای برنامه فعال است؛ اگر پشتیبان‌گیری دستگاه روشن باشد، داده‌ها ممکن است طبق تنظیمات Android در نسخه‌ی پشتیبان یا هنگام انتقال به دستگاه دیگر کپی شوند.

## نصب

جدیدترین نسخه‌ی APK را از صفحه‌ی [Releases](https://github.com/nodahani/Padingo/releases) دانلود و نصب کن.
(اگر اندروید هشدار «منبع ناشناس» داد، فقط برای مرورگر یا فایل‌منیجری که با آن دانلود کرده‌ای اجازه‌ی نصب را فعال کن.)

## ساخت از سورس

پیش‌نیاز: JDK 17 و Android SDK (یا اندروید استودیو)

```bash
git clone https://github.com/nodahani/Padingo.git
cd Padingo
./gradlew :composeApp:assembleDebug
```

خروجی در `composeApp/build/outputs/apk/debug/` ساخته می‌شود.
